# Multiplayer Everything

We write online multiplayer mods for games that never had it: classic Flash
games, and PC games made for one player, like Spooky's Jump Scare Mansion.
In most of them one player hosts a room and gets a five-letter code, friends
type it in and join. No IP addresses, no port forwarding.

- Website and game list: https://multiplayereverything.com
- Download the launcher: https://github.com/multiplayereverything/multiplayer-mods-launcher/releases/latest
- Discord: https://discord.com/invite/jnnyz2vqB5

## Suggest a game

This repo collects suggestions. Every suggestion is an issue, and the
thumbs-up reaction is the vote.

1. **Check it isn't already there.** Search the
   [open suggestions](https://github.com/multiplayereverything/multiplayereverything/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc).
   If it is, give it a thumbs-up instead of opening a new one.
2. **Suggest a game:**
   [open the form](https://github.com/multiplayereverything/multiplayereverything/issues/new?template=game-request.yml).
   Tell us the game, where to play it, and how many people should play it together.
3. **Have another idea?** Launcher or website ideas go in the
   [idea form](https://github.com/multiplayereverything/multiplayereverything/issues/new?template=idea.yml).

[Most voted first](https://github.com/multiplayereverything/multiplayereverything/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc)
is how we look at the list when picking what to work on next.

## What the labels mean

| Label | Meaning |
| --- | --- |
| `game request` | A game someone wants to play online |
| `idea` | An idea for the launcher or the website |
| `planned` | We want to do it; not started yet |
| `in progress` | Someone is building it |
| `added` | Done. Games show up in the launcher and on the website |
| `not possible` | We looked and it can't be done (the issue says why) |
| `duplicate` | Already suggested; vote on the other issue |
